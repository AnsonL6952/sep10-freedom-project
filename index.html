How do I use this tool?

How it functions is simple, you can alternate between a scalpel and pliers. in which you can use the scalpel with a box cutter with a switch in which it will retract or extend based on how far the user wants it to go. For the medical tongs, it is also retractable and can extend based on the side in which if something needs to be retractted in or large or small cavity, the user can use the retractable tongs and adjust the setting in order to do so.
